🔎 Analyse de la page de saisie des notes de MBN

Un favori à cliquer sur la page de MBN : il décrit la structure de la page, sans aucun nom ni aucune note. Rien n'est envoyé nulle part.

1. Installer le favori

  1. Affiche la barre de favoris si elle est cachée (Ctrl+Maj+B dans Chrome, Edge et Firefox).
  2. Fais glisser ce bouton dans la barre de favoris (ne clique pas dessus ici) :

    🔎 Analyser MBN ✅ Test favori
    Cliquer ces boutons ici ne fait rien : ils ne servent qu'une fois dans la barre de favoris, sur la page de MBN.

  3. Si le glisser ne marche pas : , puis crée un favori (clic droit sur la barre de favoris → Ajouter une page), nomme-le « Analyser MBN » et colle le code à la place de l'adresse.

2. L'utiliser dans MBN

  1. Ouvre dans MBN la page où tu saisis les notes d'un devoir, comme d'habitude.
  2. Clique dans la case de note du premier élève, comme si tu allais taper une note (ne tape rien). C'est utile si les cases ne deviennent modifiables qu'au clic.
  3. Clique sur le favori 🔎 Analyser MBN dans la barre de favoris.
  4. Un panneau s'ouvre avec le rapport. Relis-le : il ne doit contenir ni nom ni note (les textes sont remplacés par des X et des 9). Puis ⧉ Copier le rapport et colle-le dans la conversation avec Claude.
  5. Ferme le panneau (✕ ou Échap). La page de MBN n'a pas été modifiée ; n'enregistre rien de particulier.

Si rien ne s'affiche : clique sur ✅ Test favori sur la même page de MBN. S'il affiche « Le favori fonctionne », c'est le gros favori qui pose problème (souvent : coupé lors du glisser — recrée-le avec ⧉ Copier le code). S'il ne se passe rien non plus, MBN bloque les favoris actifs : dis-le simplement, c'est déjà une réponse utile. Si la saisie se fait sur plusieurs pages (notes, puis compétences, puis appréciations), fais l'analyse sur chacune.

3. Observer une saisie (deuxième favori)

Fais glisser aussi ce favori dans la barre : 👁 Observer MBN
Si le glisser ne marche pas : et crée le favori à la main, comme pour le premier.

  1. Dans MBN, ouvre la saisie d'un devoir dont les résultats ne sont pas encore publiés si possible, et clique sur un élève de la liste pour afficher son panneau à droite.
  2. Clique sur 👁 Observer MBN. Un bandeau violet foncé apparaît en bas à droite : l'observation commence.
  3. Fais une saisie comme d'habitude, sans te presser :
    • change la note de cet élève (tape une autre note), puis appuie sur Tab ;
    • change une compétence dans sa liste déroulante ;
    • s'il y a une case de remarque, tape un mot ;
    • clique sur l'élève suivant dans la liste, puis reviens sur le premier et remets tout comme avant (note, compétence, remarque).
  4. Clique sur Terminer dans le bandeau. Le rapport s'affiche : relis-le, ⧉ Copier le rapport, colle-le à Claude.

L'observation note les événements (clic, frappe, changement), les champs modifiés et les requêtes envoyées à MBN — leur adresse et le nom de leurs paramètres, jamais les valeurs ; les notes et les textes sont remplacés par leur forme. Elle ne modifie rien elle-même et s'arrête à « Terminer » ou « Annuler » (ou en rechargeant la page).

4. Relever le code de saisie de MBN (troisième favori)

Fais glisser ce favori dans la barre : 🧩 Code MBN
Si le glisser ne marche pas : .

  1. Dans MBN, ouvre la saisie d'un devoir et clique sur un élève de la liste.
  2. Clique sur 🧩 Code MBN : il recopie le programme de MBN qui gère la saisie (ses fonctions et ce qui réagit à la case de note). C'est du code, pas des données ; les textes qu'il contient sont quand même anonymisés.
  3. ⧉ Copier, puis colle-le à Claude (c'est long, c'est normal).
